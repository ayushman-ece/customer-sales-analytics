## 📌 Project Overview

The Customer Sales Analytics & Insights System is designed to help businesses understand their sales performance and customer purchasing behavior.

It processes sales data from CSV files, calculates important business metrics, identifies top-performing products and customers, analyzes monthly revenue, and generates visual and downloadable analytical reports.

The project uses Python, Pandas, and Matplotlib to demonstrate practical data analysis techniques.

## 🎯 Project Objectives

- Analyze overall business sales performance.
- Calculate total revenue, orders, and units sold.
- Identify best-performing products.
- Discover high-value customers.
- Track monthly revenue trends.
- Generate meaningful sales visualizations.
- Export analytical reports into CSV files.
- Validate input data before processing.

## ✨ Features

### 📈 Sales Performance Analysis
- Total revenue calculation.
- Total unique orders.
- Total units sold.
- Average Order Value (AOV).

### 🛍️ Product Performance Analysis
- Product-wise sales analysis.
- Total units sold per product.
- Revenue generated by each product.
- Ranking products by revenue.

### 👥 Customer Analysis
- Customer-wise spending analysis.
- Total orders per customer.
- Identification of top-spending customers.

### 📅 Monthly Revenue Analysis
- Monthly revenue calculation.
- Monthly order tracking.
- Revenue trend analysis.

### 📊 Data Visualization
- Monthly revenue bar chart.
- Clear chart labels and titles.
- Automatic PNG chart generation.

### 📁 Automated Report Generation
Generates four CSV reports:

- `sales_report.csv`
- `product_report.csv`
- `customer_report.csv`
- `monthly_report.csv`

### 🛡️ Data Validation
- Required column validation.
- Missing value detection.
- Numeric data conversion.
- Invalid quantity and price checks.
- Date format validation.

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/ayushman-ece/customer-sales-analytics.git
```

### 2. Navigate to the project directory

```bash
cd customer-sales-analytics
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the virtual environment

Windows:

```bash
.venv\Scripts\activate
```

Linux / macOS:

```bash
source .venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the project

```bash
python main.py
```
